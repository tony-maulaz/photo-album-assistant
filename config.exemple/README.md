# Exemple de dossier de configuration

Copier ce dossier en `config/`, à côté de `album-photos.html`, puis remplacer les coordonnées d'exemple — ou tout gérer depuis la
page Configuration de l'application. Format : `docs/SPEC_APP.md` § 8.
Le vrai dossier `config/` n'est jamais versionné (coordonnées du domicile).
