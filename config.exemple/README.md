# Example configuration folder / Exemple de dossier de configuration

**English.** Copy this folder anywhere (for example as `config/` next to
`album-photos.html`), replace the example coordinates, then choose it on the
**Configuration** page of the app (menu ☰) — or create everything from that
page. It holds your known places (home, grandparents, school…), family
calendars (`.ics`) and cameras. Never publish your real configuration folder:
it contains your home address. Format: `docs/SPEC_APP.md` § 8 (French).

**Français.** Copier ce dossier en `config/`, à côté de `album-photos.html`,
puis remplacer les coordonnées d'exemple — ou tout gérer depuis la page
Configuration de l'application. Format : `docs/SPEC_APP.md` § 8. Le vrai
dossier `config/` n'est jamais versionné (coordonnées du domicile).
