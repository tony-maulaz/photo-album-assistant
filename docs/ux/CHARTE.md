# Charte graphique

**État : phase d'exploration** (D109). Aucun style n'est figé : les agents
d'interface sont entièrement libres sur le visuel (`docs/ux/CADRE_REVUE.md`,
« Liberté visuelle »).

Quand l'utilisateur aura trouvé un style qui lui plaît, il sera décrit ici
(police, échelle de tailles, palette et sens des couleurs, boutons, icônes,
espacements, rayons et ombres, disposition type des pages, captures de
référence), puis cet état passera à **figée**. À partir de là, l'agent
`gardien-style` le fera respecter en priorité, et seul l'utilisateur pourra
le faire évoluer.
